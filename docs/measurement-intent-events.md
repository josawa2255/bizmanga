# 相談導線の補助イベント（2026-10-02）

## 変更範囲

`js/bm-tracking.js` に相談導線のGA4補助イベントを追加。既存のこのJSを読み込むページに適用する。HTML、見た目、リンク先、フォーム送信処理、Google広告のコンバージョンラベルは変更していない。

| イベント | 発火する操作 | 意味しないこと |
|---|---|---|
| `contact_link_click` | 別ページから同一オリジンの `/contact` へのクリック | フォーム到達・送信完了ではない |
| `line_click` | HTTPSの `line.me` / `lin.ee` へのクリック | 友だち追加・相談受信ではない |
| `phone_click` | `tel:` リンクへのクリック | 発信・通話成立ではない |
| `download_link_click` | 別ページから同一オリジンの `/download` へのクリック | 資料ダウンロード完了ではない |

- 送信先は既存GA4の `G-Q1T3033Q3W` のみ。
- 追加するパラメータはクエリなしの正規化した `page_path`。リンク全文、リンクのクエリ、氏名、メール、電話番号を新イベントのパラメータへ入れない。既存Googleタグが自動収集する共通パラメータの設定は変更しない。
- 本番ホスト以外と `isTrusted === false` のクリックは、新イベントを送らない。既存のGA4基本タグ・既存イベントのローカル送信までは抑止しない。
- 既存のload時gtag初期化を優先する。ページ読込完了前のクリックはloadまで待つため、それより先に離脱した場合は取得できない。全ページのタグ初期化タイミング変更は別対応。
- `preventDefault` / `stopPropagation` は使わず、遷移と既存の広告クリック計測を維持する。
- `generate_lead` とGoogle広告の `conversion` は増設しない。

## 安定性の修正

スクリプト二重読込のガード、破損したsessionStorageの型チェック、非スクロールページのゼロ除算防止、スクロール率を0〜100へ制限、要素以外のクリックターゲットへの対処を追加。

## 管理画面で別途必要な作業（このコード変更では未実施）

GA4の `generate_lead` のキーイベント化、包括的な `click` のキーイベント解除、Google広告の主要/補助目標とカスタム目標の整理は管理画面または対応する管理APIで行う。この4つの補助クリックを、問い合わせ完了の代わりに主要目標へ登録しない。フォーム成功タグと広告アクションの対応を確認し、直接タグとGA4インポートで同じ成果を二重計上しない。

## 検証

`node --check js/bm-tracking.js`

`node tools/test-bm-tracking.cjs`

NodeのVMで30項目を検証する。実際の問い合わせ、Googleタグへの通信、LINEへのアクセス、電話発信は行わない。テスト合格はGA4での受信やGoogle広告への成果反映を証明しない。本番公開後、通常の利用に伴う受信を別途確認する。
